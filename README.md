# Nader Kasabri — Portfolio

Personal portfolio website of Nader Kasabri — graphic & UI/UX designer and AI creative from Yafa an-Naseriyye.

- Trilingual: English, Arabic, Hebrew (RTL support)
- 3D scene with three.js, scroll animations with GSAP
- Single self-contained `index.html` — no build step

**Live via GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
